01 / Project summary

Research problem

Compare predictive approaches for diabetes classification from structured health data while accounting for screening-relevant errors.

Method

Seven machine-learning models and two tabular deep-learning models, with feature engineering, held-out testing and SHAP interpretation.

My contribution

Data preparation, leakage-aware transformations, model development, comparative evaluation, interpretation and decision-support design.

02 / Analysis map

From patient data to interpretable prediction

03 / Verified results

Ensemble models led the comparison

Dataset

1,879 patient records

Models

7 ML + 2 tabular DL

Best test ROC-AUC

LightGBM · 0.9606

Best accuracy / F1

XGBoost · 0.9229 / 0.9003

LightGBM and XGBoost outperformed the tabular deep-learning models on the held-out test set. Evaluation emphasized recall and false-negative burden alongside aggregate performance.

04 / Interpretation

Clinically meaningful predictors

SHAP analysis identified HbA1c, fasting blood sugar and their engineered interaction as the strongest contributors, followed by symptom burden and cardiometabolic variables. The analysis links model performance with feature-level interpretation rather than treating prediction as a black box.

05 / Evidence boundary

Research, not deployment

The analysis uses one public dataset and requires external validation before any clinical use. Validation strategies differed between classical and deep-learning models, and the system design remains a proposed decision-support framework rather than a deployed clinical tool.
